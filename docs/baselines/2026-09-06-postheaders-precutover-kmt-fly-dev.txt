## Notes (hand-added the same run, read-only; not produced by baseline.sh)

State: kmt.fly.dev after #147 (static headers, brand cache, robots/sitemap,
405 on non-GET/HEAD static), #167 (six security headers on every response,
the canonical redirect, /api/ unknown-path 404, // collapse) and #178
(malformed percent-encoding answers the app shell, not 500). KMT_CANONICAL_HOST
is unset, so no cutover has happened: this is the state the flip starts from.
All four hostnames (kmt.fly.dev, the apex, www, order) serve 200 with no
redirect; the app is host-independent until the secret is set.

The static-header seam, which baseline.sh does not probe:
  GET /brand/icon-32.png (served by backend/static.mjs) -> 200 with all six
    headers (Content-Security-Policy, X-Content-Type-Options, X-Frame-Options,
    Referrer-Policy, Permissions-Policy, Cross-Origin-Opener-Policy) plus
    Content-Type image/png and Cache-Control public, max-age=86400,
    stale-while-revalidate=604800 and an ETag. #147 writeHead merges with
    #167 setHeader rather than replacing it, so the headers ride a static file.
  Conditional GET (If-None-Match) -> 304 with the CSP, nosniff, Content-Type
    and Cache-Control still present.

GET /api/catalog -> Cache-Control public, max-age=300 (was no-store before
  #154/#169); ?size=215/60R16 -> 200, one size only (~9.6 KB brotli) instead
  of the ~170 KB full list. (baseline.sh probes the catalog with GET; the
  routes list above uses HEAD for status only, so it shows no cache-control.)

Known quirk, not a fault: HEAD /api/catalog -> 401, because the catalog
handler is GET-only and a HEAD falls through to the session gate; GET is
public 200. HEAD /api/health -> 401 for the same reason (already in the
morning capture). No impact: the flow, the audits and the machine health
check all use GET. Meet it as a known quirk, not a discovery.

When the flip happens the only new behaviour is the 301: every non-canonical
host answers 301 to KMT_CANONICAL_HOST (except /api/health), and everything
above must stay put. A difference other than the 301 is a finding.
